# CopperS Бугалт — десктоп-версия

Обёртка на Electron вокруг того же приложения (index.html), что и веб-версия.
Работает как обычная программа для Windows/macOS/Linux, со своей иконкой,
своим окном, без браузера.

## Важно про данные

Приложение хранит все данные (продажи, товары, настройки) в **localStorage
внутри самого приложения** — это отдельное, изолированное хранилище,
никак не связанное с версией на claude.ai или в браузере.

Если хочешь перенести текущие записи:
1. В веб-версии (на claude.ai) нажми "Экспорт CSV"
2. Установи и открой десктоп-версию (см. ниже)
3. Перетащи CSV-файл в окно импорта

## Требования

- Node.js 18+ (https://nodejs.org) — нужен только на компьютере, где
  собираешь установщик. У человека, который потом просто ставит готовую
  программу, Node.js не нужен.

## Самый простой способ (Windows, без терминала)

Дважды кликни на файл **`build_exe.bat`** в этой папке. Он сам:
1. Проверит, установлен ли Node.js (если нет — подскажет, откуда скачать)
2. Установит всё нужное
3. Соберёт готовый `.exe`
4. Откроет папку `dist` с готовым установщиком

Ничего печатать не нужно — просто подожди, пока в окне не появится "Готово!".

## Запуск в режиме разработки (проверить, что всё работает)

```bash
cd coppers-desktop
npm install
npm start
```

Откроется окно программы.

## Сборка установщика

```bash
npm run build:win     # .exe для Windows
npm run build:mac     # .dmg для macOS
npm run build:linux   # AppImage для Linux
```

Готовый файл появится в папке `dist/`. Именно его раздаёшь себе на другие
компьютеры или кому угодно — устанавливается как обычная программа,
второй раз Node.js/npm не нужны.

Учти: собрать .exe для Windows проще всего на самой Windows (или через
Wine на Linux); аналогично .dmg для macOS собирается надёжнее всего на Mac
из-за подписи приложений. Если соберёшь на Linux — AppImage точно получится,
Windows/Mac-сборки там тоже технически возможны, но могут потребовать
дополнительной настройки.

## Иконка приложения (необязательно)

Сейчас используется иконка Electron по умолчанию. Если захочешь свою —
положи файл `icon.png` (минимум 512×512) в эту папку и добавь в `package.json`
в секции `build.win`/`build.mac`/`build.linux` поле `"icon": "icon.png"`.

## Обновления в будущем

Раз в приложение внесут изменения (например, здесь в чате) — нужно будет:
1. Скачать обновлённый index.html
2. Заменить им файл `index.html` в этой папке
3. Заново запустить `npm run build:...`

Автообновления "из коробки" не настроены — при желании это отдельная
задача (electron-updater + сервер для раздачи новых версий).
